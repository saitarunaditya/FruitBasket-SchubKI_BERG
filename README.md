# FruitBasket - SchubKI National AI Hackathon 2026

**Challenge:** Mind Reading Using Machine Learning and EEG
Given a 3-second EEG recording, rank 102 candidate videos from most to least likely
to have elicited the brain activity.

## TL;DR - best approach

**Option B: BERG features + per-subject Ridge regression** (`05_make_submission.ipynb`).

A publicly available pretrained brain-encoding model (**BERG**,
`eeg-things_eeg_2-vit_b_32`) turns each video into a stimulus descriptor. We then
train a small per-subject encoder (StandardScaler -> PCA(0.95) -> StandardScaler ->
RidgeCV) that maps that descriptor to the subject's **real** EEG, and rank the test
videos by correlating predicted vs measured EEG.

Validation (sub-01): **top-1 0.0490, top-5 0.2157, median rank 20.0**
(chance 0.0098 / 0.0490; AlexNet baseline 0.0392 / 0.1176).

## Submission files

- `eeg-mind-reading-challenge/sub-05_ranked_candidate_list.npy`
- `eeg-mind-reading-challenge/sub-06_ranked_candidate_list.npy`

Each is an integer array of shape `102 x 102`, values are video IDs `1001..1102`,
ordered most -> least likely, with row `i` matching the original (unsorted) order of
`tst/sub-XX_tst.npy`. Generated by `05_make_submission.ipynb`.

## Environment

- Python **3.11+** (developed/run on 3.13.7; notebook 07 uses only numpy/scipy/sklearn
  and is pure-3.11 compatible).
- Install:
  ```
  pip install numpy scipy scikit-learn opencv-python matplotlib
  pip install -U "git+https://github.com/gifale95/BERG.git"   # for notebooks 03-06
  ```
- Windows note: BERG reads UTF-8 YAML model cards; on Windows set `PYTHONUTF8=1` (or
  use the UTF-8 `open()` patch cell included at the top of notebooks 03-06).

## Pretrained models used (public, released before the hackathon)

- **BERG** Brain Encoding Response Generator - model `eeg-things_eeg_2-vit_b_32`
  (THINGS-EEG2, ViT-B/32 backbone). Repo: https://github.com/gifale95/BERG
  Weights are downloaded from the BERG public AWS bucket (not committed).
- **AlexNet** via net2brain (`features.3`) for the baseline and notebook 07.

## Data not in the repo (per challenge rules: no videos/frames)

The following organizer-provided / generated data is git-ignored and must be placed
locally under `eeg-mind-reading-challenge/`:

- `stimuli_train/`, `stimuli_test/` - stimulus videos (.mp4)
- `frames/`, `frames_test/` - extracted video frames (regenerated by the notebooks)
- `trn/`, `tst/`, `tst_stim/` - EEG recordings and ground-truth labels
- `features/`, `features_test/` - AlexNet features (regenerated by net2brain)
- `features_berg/`, `features_vit/` - cached BERG/ViT features (regenerated)
- `brain-encoding-response-generator/` - BERG model weights (downloaded from AWS)

## How to reproduce the submission

1. Place the data folders above under `eeg-mind-reading-challenge/`.
2. Download the BERG subject-01 EEG weights:
   ```
   python -m awscli s3 sync --no-sign-request \
     s3://brain-encoding-response-generator/encoding_models/modality-eeg/train_dataset-things_eeg_2/model-vit_b_32 \
     ./eeg-mind-reading-challenge/brain-encoding-response-generator/encoding_models/modality-eeg/train_dataset-things_eeg_2/model-vit_b_32 \
     --exclude "*" --include "*subject-01.npy"
   ```
3. Run `05_make_submission.ipynb` top to bottom. It self-checks the format/score on
   sub-01, then writes `sub-05_ranked_candidate_list.npy` and
   `sub-06_ranked_candidate_list.npy`.
